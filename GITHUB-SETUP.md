# Pasta para GitHub

A pasta pronta para virar repositório é:

`github/ts-se-tool-python/`

Não publique `projeto_atual/`: ela contém perfis reais, binários e código legado usado apenas como referência local. O novo projeto aponta para essa pasta durante o redesenvolvimento.

Para iniciar:
```powershell
cd github\ts-se-tool-python
git init
git add .
git commit -m "chore: bootstrap TS SE Tool Python harness"
```

Depois rode o Codex na pasta do repositório e peça: `Leia AGENTS.md e execute PROJECT.md seguindo as tasks em ordem.`
